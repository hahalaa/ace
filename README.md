# Ace 🎾

Ever wondered who's going to win Wimbledon before a single ball is hit? Or curious how a match between two players who've never faced each other would actually play out? Ace simulates it, point by point, game by game, set by set.

**Try Ace here → https://play-ace.onrender.com**

---

Match data from [TML-Database](https://github.com/Tennismylife/TML-Database), offered in partnership with [CanalTenis](https://canaltenis.com/), used here for educational and research purposes. TML-Database was originally inspired by Jeff Sackmann's [ATP Matches Dataset](https://github.com/JeffSackmann/tennis_atp) (CC BY-NC-SA 4.0).
